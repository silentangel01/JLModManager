# JLModManager

七日杀 Windows Mod 管理器。

- 手动选择 Mods 目录，接管已安装模组。
- 扫描下载目录，导入 ZIP 或已解压模组；RAR、7z 需先解压。
- 启用、禁用和切换模组版本，保存方案、游戏版本备注，一键应用并启动。
- 导出、导入整合包，检查重复模组和文件变化，支持部署回退及手动存档备份。
- 结合名称、版本和关键文件 SHA-256 识别已收录的模组分支。

身份指纹目前仅收录两个自制模组；前置依赖与游戏版本兼容性自动检查尚未完成。

## 使用

从 Releases 下载 Windows x64 压缩包，完整解压后运行 `JLModManager.exe`。选择游戏的 Mods 目录，导入或接管模组，再保存、应用方案。

更新时保留 `Data` 目录。修改部署前请关闭游戏。管理器不会编辑单个模组的配置。

## 构建

Windows、.NET 10 SDK、PowerShell：

```powershell
./Build.ps1 -Test
```

程序输出到 `publish`，测试仅使用隔离目录。
